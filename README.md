# DriftMod - BX Pack
*The ultimate drift-centric suspension and steering overhaul for the BX chassis in BeamNG.drive.*

## 🏎️ Overview
**DriftMod** is a specialized modification designed to transform the base BX vehicle into a precision drift machine. It provides a highly tunable platform that balances aggressive geometry with responsive handling, specifically optimized for high-angle drifting and realistic Force Feedback (FFB).

## ✨ Key Features
- **Advanced Suspension Geometry:** Features custom double wishbone front suspension with adjustable KPI, caster, and camber.
- **Dynamic Steering Control:** Fully variable steering lock, speed, and wheel degree settings.
- **Realistic Force Feedback:** Integrated FFB damping and gain adjustments, mapped directly to your steering inputs for a visceral driving experience.
- **Quick-Adjust Variables:** Modify key drift parameters on the fly through the in-game UI.

## 🛠️ Technical Highlights
- **Variable-Driven System:** Every major component (Track Offset, Camber, Rigidity, Brake Bias) is tied to a real-time variable registry for seamless adjustments.
- **High-Fidelity Physics:** Optimized JBEAM configurations ensure stable performance during high-speed maneuvers.
- **Integrated Controller:** Custom Lua controller handles complex steering logic and FFB scaling.

## 📥 Installation
1. Extract the contents of the `driftmod_bx_pack_extracted` folder.
2. Place the `vehicles` folder into your BeamNG.drive mods directory.
3. Select the **DriftMod** vehicle from the vehicle selector.
